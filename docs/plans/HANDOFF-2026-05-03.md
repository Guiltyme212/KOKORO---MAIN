## Things to be careful about

- **Do not revert TS commits** (04f66b5..86f255d). The user wants them in history for context.
- **Do not commit `api/.env`.** It's in `api/.gitignore`. The values are placeholders, but committing it sets a bad pattern.
- **Suno endpoint shapes** at acedata.cloud have shifted in the past. When implementing Task 12, the dispatched subagent should be told to verify against acedata.cloud's live docs before assuming `/audios`, `/audios/extend`, field names like `persona_id`, `lyric`, `reference_audio_urls` are still correct.
- **Anthropic SDK API caching syntax** — verify the `system=[{type:"text", text:..., cache_control:{type:"ephemeral"}}]` shape against the latest `anthropic` Python SDK before assuming it works. Recent versions support cached system blocks; very old versions don't.
- **Pet name regex** in `types.py` is `^[^\n\r]+$` — pet names may contain Cyrillic (`зай`, `котёнок`), spaces, hyphens. Don't tighten it.
- **Audio MP3 size**: 5–10 MB per file. The filesystem driver writes to `./blob-data/` in dev. This must be in `.gitignore` (it already is).
- **ANTHROPIC_API_KEY** was leaked in chat earlier. After this session, the user must rotate it via the CliProxy config. Mention this in your first user-facing reply.
- **Latency 45–90 seconds per /meditations request** is normal. The frontend's `Composing.tsx` already shows a 9-second loader animation that needs to be extended (Task 19) into a real progress experience tied to backend stage hints.
- **Templates are at the repo root, not inside api/.** The loader resolves `Path.cwd().parent / "templates"` because uv runs from `api/`. If the cwd assumption breaks (e.g. when running tests from a different dir), pass `root_dir=` explicitly.
